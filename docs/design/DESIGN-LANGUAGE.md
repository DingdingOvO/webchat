# WebChat 设计语言 v3 —「清明」

> 一句话：**用留白和层次组织信息，而不是用线框和阴影。**
> 参考气质：Stripe 的通透、Vercel 的克制、Linear 的节奏。

本文件是 WebChat 唯一的设计依据。任何页面、组件、新增样式都必须引用此处的令牌，
**不允许出现硬编码色值、硬编码间距、或内联 style 中的视觉属性。**

---

## 1. 原则

| 原则 | 含义 | 反面（v2 的病） |
| --- | --- | --- |
| **留白优先** | 用间距和字号建立层次 | 靠加边框、加分割线区分区块 |
| **单色阶** | 整站只有一条灰阶 + 一个点缀色 | 蓝、绿、橙各占一块，视觉打架 |
| **边界靠"面"，不靠"线"** | 用背景色差分层，线只做最后一档补充 | 到处 1px 边框，页面像表格 |
| **动效克制且一致** | 只有一种时长、一种缓动 | 有的 0.12s 有的 0.3s，手感散 |
| **密度统一** | 全局同一套间距刻度 | 顶栏 8px、列表 12px、消息 16px |
| **深浅双模对等** | 深色不是反相，是独立校准 | 深色下对比度不够、发灰 |

---

## 2. 色彩

### 2.1 灰阶（主结构色）

整站只用这一条中性阶。刻意偏一点点冷（蓝灰），让大留白不显脏。

| 令牌 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `--n-0` | `#ffffff` | `#0f1115` | 卡片/最亮面 |
| `--n-25` | `#fcfcfd` | `#141619` | 应用底色 |
| `--n-50` | `#f8f9fa` | `#191c20` | 次级面板、代码块 |
| `--n-100` | `#f1f3f5` | `#20242a` | hover 底 |
| `--n-200` | `#e9ecef` | `#282d34` | active 底 |
| `--n-300` | `#dee2e6` | `#363c45` | 强分割线 |
| `--n-400` | `#adb5bd` | `#4b535e` | 占位符、禁用图标 |
| `--n-500` | `#868e96` | `#6b7480` | 三级文字 |
| `--n-600` | `#5c636a` | `#98a1ac` | 二级文字 |
| `--n-700` | `#3d4349` | `#c4cbd3` | 正文（深色模式） |
| `--n-800` | `#24292e` | `#e6e9ed` | 标题 |
| `--n-900` | `#14171a` | `#f5f7f9` | 强调标题 |

### 2.2 语义令牌（**页面只能用这层，不直接用灰阶**）

| 令牌 | 浅色取值 | 深色取值 | 用途 |
| --- | --- | --- | --- |
| `--bg` | `--n-25` | `--n-0` | 页面底 |
| `--surface` | `--n-0` | `--n-50` | 卡片、面板 |
| `--surface-sunken` | `--n-50` | `--n-25` | 输入框、内嵌区 |
| `--border` | `--n-200` | `--n-200` | 唯一分割线色 |
| `--border-strong` | `--n-300` | `--n-300` | 输入框、需强调的边 |
| `--text` | `--n-800` | `--n-800` | 正文 |
| `--text-secondary` | `--n-600` | `--n-600` | 说明文字 |
| `--text-tertiary` | `--n-500` | `--n-500` | 时间戳、辅助 |
| `--text-disabled` | `--n-400` | `--n-400` | 禁用态 |

### 2.3 点缀色（**全站只一个**）

| 令牌 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `--accent` | `#2563eb` | `#4d84f5` | 主按钮、链接、自己气泡、选中态 |
| `--accent-hover` | `#1d4ed8` | `#6b98f7` | hover |
| `--accent-subtle` | `#eff4ff` | `#1a2338` | 选中行底、标签底 |
| `--accent-text` | `#1d4ed8` | `#93b4fb` | 点缀色上的文字（浅底深字） |

### 2.4 功能色（仅状态提示，禁止装饰性使用）

| 令牌 | 浅色 | 用途 |
| --- | --- | --- |
| `--success` / `--success-subtle` | `#0f9d58` / `#eaf7f0` | 在线、成功 |
| `--danger` / `--danger-subtle` | `#d93838` / `#fdeced` | 错误、未读红点 |
| `--warning` / `--warning-subtle` | `#b7791f` / `#fdf6e7` | 警示 |

### 2.5 对比度硬约束

- 正文 `--text` on `--surface`：≥ **7:1**（AAA）
- 二级文字：≥ **4.5:1**（AA）
- 三级文字（时间戳等非关键信息）：≥ **4.5:1**
- 图标、边框等非文字：≥ **3:1**
- **深色模式必须逐项复测，不能靠反相凑合**

## 3. 间距

8px 基准，4px 为半档。**页面里只允许出现这些值。**

| 令牌 | 值 | 典型用途 |
| --- | --- | --- |
| `--s-1` | 4px | 图标与文字之间 |
| `--s-2` | 8px | 紧凑元素内边距 |
| `--s-3` | 12px | **列表项内边距（统一）** |
| `--s-4` | 16px | 面板内边距、卡片间距 |
| `--s-5` | 20px | 区块内边距 |
| `--s-6` | 24px | 区块之间 |
| `--s-8` | 32px | 页面左右留白（窄屏） |
| `--s-10` | 40px | 大区块间隔 |
| `--s-12` | 48px | 章节间隔 |
| `--s-16` | 64px | 首屏上下留白 |
| `--s-24` | 96px | 落地页大留白 |

**统一节奏规则（v2 的主要病根）**

- 所有列表项：上下 `--s-3`，左右 `--s-4`
- 所有面板顶栏：上下 `--s-3`，左右 `--s-4`
- 所有内容区左右内边距：`--s-5` 或 `--s-6`
- 消息气泡之间：`--s-3`

## 4. 圆角

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--r-xs` | 4px | 标签、徽标 |
| `--r-sm` | 6px | 按钮（小）、输入框（小） |
| `--r-md` | 8px | **按钮、输入框（默认）** |
| `--r-lg` | 10px | 面板、气泡 |

| `--r-full` | 9999px | 头像、胶囊 |

规则：**容器越大圆角越大**，同级元素圆角必须一致。

## 5. 排版

字体栈：系统 UI 优先，中文回退 PingFang / 微软雅黑。

| 令牌 | 字号 / 行高 | 字重 | 用途 |
| --- | --- | --- | --- |
| `--t-display` | 40px / 1.15 | 700 | 落地页主标 |
| `--t-h1` | 28px / 1.25 | 650 | 页面标题 |
| `--t-h2` | 20px / 1.35 | 600 | 区块标题 |
| `--t-h3` | 16px / 1.45 | 600 | 卡片标题 |
| `--t-body` | 14px / 1.6 | 400 | **正文默认** |
| `--t-body-lg` | 15px / 1.65 | 400 | 消息内容、长文 |
| `--t-sm` | 13px / 1.55 | 400 | 次要说明 |
| `--t-xs` | 12px / 1.5 | 400 | 时间戳、标签 |

- 正文最大宽度 **68ch**（约 640px），避免长行难读
- 标题字间距 `-0.02em`，正文 `0`
- 中文不用斜体

## 6. 层次：用「面」不用「线」

这是本次设计语言的核心手段，替代 v2 到处画边框的做法。

| 层级 | 实现 | 示例 |
| --- | --- | --- |
| L0 页面底 | `--bg` | 应用背景 |
| L1 面板 | `--surface` + 无阴影 + 无边框 | 聊天左侧栏 |
| L2 卡片 | `--surface` + `--border` 1px | 登录卡片 |
| L3 浮层 | `--surface` + `--shadow-md` | 弹窗、下拉 |
| 凹陷 | `--surface-sunken` + 无边框 | 输入框、搜索结果区 |

**阴影只有三档，且只在浮层使用：**

| 令牌 | 值 |
| --- | --- |
| `--shadow-sm` | `0 1px 2px rgba(16,24,40,.05)` |
| `--shadow-md` | `0 4px 16px rgba(16,24,40,.08), 0 1px 3px rgba(16,24,40,.04)` |
| `--shadow-lg` | `0 12px 32px rgba(16,24,40,.12), 0 2px 8px rgba(16,24,40,.06)` |

> 静止状态的内容卡片**一律不用阴影**。

## 7. 栅格与容器

v2 三个页面三种宽度，本次统一：

| 容器 | 最大宽度 | 用于 |
| --- | --- | --- |
| `--w-narrow` | 480px | 登录 / 注册 |
| `--w-content` | 720px | 设置、表单、文档正文 |
| `--w-wide` | 1120px | 落地页、文档三栏 |

响应式断点：`640px`（手机）、`900px`（平板）、`1200px`（桌面）。

应用内（聊天页）为**满屏三区**布局，不受容器宽度限制：

```
┌─────────────┬──────────────────────────────┐
│  侧栏 300px  │        会话区 flex:1          │
│  会话/联系人  │                              │
└─────────────┴──────────────────────────────┘
```

## 8. 动效

| 令牌 | 值 |
| --- | --- |
| `--ease` | `cubic-bezier(.2, 0, 0, 1)` |
| `--dur-1` | 120ms（颜色、透明度） |
| `--dur-2` | 200ms（位移、尺寸） |

- 只允许 **opacity / transform / color / background-color / border-color** 参与过渡
- 禁止对 `height`、`top`、`margin` 做过渡（会掉帧）
- 必须尊重 `prefers-reduced-motion`

## 9. 状态规范

每个可交互元素必须有四态：default / hover / active / disabled，且**深色下同样成立**。

| 元素 | hover | active | disabled |
| --- | --- | --- | --- |
| 主按钮 | `--accent-hover` | 下沉 0.5px | 40% 不透明度 + `not-allowed` |
| 次要按钮 | 底色 → `--n-100` | 底色 → `--n-200` | 文字 `--text-disabled` |
| 列表项 | 底色 → `--n-100` | — | — |
| 列表项（选中） | `--accent-subtle` | — | — |

焦点：统一 `:focus-visible` 用 `0 0 0 3px accent/20%` 外环，**不改变元素尺寸**。

## 10. 图标

**统一为「面性」（实心）风格**，全部集中在 `src/components/Icons.tsx`。

### 10.1 为什么改

v3 早期用的是 Fluent 线框图标（描边路径）。在 20px 渲染尺寸下，细线会缩成一片
灰线，视觉重量严重不足，在一排小按钮里看起来像「一堆乱码笔画」。

实心图标在同等尺寸下的墨量约为线框的 2～3 倍，辨识度和点击意图都更明确。

### 10.2 规则

| 规则 | 说明 |
| --- | --- |
| **实心为主** | 使用 `fill` 填充的形状，不写 `stroke` |
| **负空间刻画细节** | 内部结构靠「挖空」表达（如搜索镜片内挖一个孔），而不是描边 |
| **统一 20×20 viewBox** | 四周留 ≥1.5px 安全边距，保证光学大小一致 |
| **只依赖 `currentColor`** | 不写死颜色，跟随主题与父级文字色 |
| **`aria-hidden="true"`** | 图标是装饰，语义由外层 `aria-label` 或相邻文字承担 |
| **圆角 1～1.5px 量级** | 与全局 `--r-sm` 的圆润感呼应，不出现尖角突变 |

### 10.3 新增图标

1. 在 `Icons.tsx` 里用 `<Icon>` 包一层，只写 `path`/`circle` 等填充形状。
2. 先自检：**把 fill 换成黑色看是否是一块实心图形**；若轮廓靠细线成立，重画。
3. 不要从 Fluent / Material 直接复制线框路径 —— 风格会立刻不统一。

### 10.4 头像色相

列表、联系人、消息分组头的头像使用**按 id 稳定映射**的 8 组色相（`components/avatarHue.ts`）。

- 同一个人在任何位置都是同一个颜色；
- 浅色为「浅底深字」，深色为「深底浅字」，两组都满足 ≥4.5:1；
- 群组固定用强调色，与个人区分。

> 反面：v3 早期所有头像统一 `--n-200` 灰底灰字，一列头像糊成一片，
> 扫读时完全分不出谁是谁。

## 11. 文案

**面向普通用户，不写技术实现。**

| 反例（v3 早期首页） | 正例 |
| --- | --- |
| 热消息驻留 Redis，冷消息落盘 MongoDB | 聊天历史自动保存，换台设备打开也还在 |
| 私聊与群聊共用一套投递链路，多实例部署也能保持同步 | 消息即发即到，不用刷新页面 |
| 实时私聊、群组协作、好友管理 | 搜昵称就能加好友，拉个群也只要几秒 |
| 基于 Spring Boot 与 React 构建 | （删除，用户不关心技术栈） |

判断标准：**这句话对「只想找人聊天的人」有意义吗？** 没有就删。

## 12. 实现约定

1. 所有视觉值走 CSS 变量，**组件内联 style 只允许写布局（flex/grid）**，不写颜色、阴影、圆角。
2. 页面样式一律 CSS Modules，类名用语义命名（`.composer` 而非 `.input2`）。
3. 深色模式通过 `:root[data-theme="dark"]` 覆盖语义层，**灰阶与语义令牌各定义一次**。
4. 新增组件前先来本文件查令牌，缺什么先补令牌再用。
5. **容器对齐**：外层元素负责水平 padding，内层负责 `max-width` + `margin: 0 auto`。
   不要把 padding 写在同时带 `max-width` 的元素上 —— 否则它的内容左缘会比别的区块多出 padding。

---

## 13. 消息列表分组

连续消息必须**合并成组**，而不是每条独立成行：

- 同一发送者、且与上一条间隔 < **5 分钟** → 并入同组；
- 组内气泡间距 2px，视觉上合成「一坨」；
- **时间戳只在组尾出现一次**；
- 群聊里每组带一次发言人（小头像 + 名字），私聊不带。

> 反面：v3 早期给每条消息都渲染时间戳，同一人连发三条就散落三行小字，
> 页面底部一片噪点。
