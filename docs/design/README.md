## 三条最容易违反的规则

1. **页面里不允许出现硬编码色值。** 一律走 `var(--text)` / `var(--surface)` 这类语义令牌，
   这样深色模式才能自动生效。直接写 `#333` 会在深色下失效。
2. **静止内容不用阴影。** 层次靠背景色差（`--bg` / `--surface` / `--surface-sunken`）表达，
   阴影只留给弹窗等真正浮起的元素。
3. **间距只用刻度值。** `--s-1` 到 `--s-24`，不要写 `padding: 7px 13px`。

## 深色模式

- 令牌由 `:root[data-theme="dark"]` 整体覆盖，**组件不需要写任何深色分支**
- 由 `ThemeContext` 维护，三档：跟随系统 / 浅色 / 深色，持久化到 `localStorage`
- 切换入口：应用顶栏的图标按钮、设置页的分段控件、登录页右上角
- 新增颜色令牌时，**必须同时在浅色与深色两处定义**

## 历史

- **v1 / v2「Aero」**：多套并行命名（`--fs-*` 与 `--text-*`、`--p*` 与 `--space-*`），
  卡片靠阴影与蓝调渐变分层，存在未定义变量 `--px`。已废弃。
- **v3「清明」**：单一命名体系、语义令牌分层、以留白与面色建立层次、完整双模支持。
